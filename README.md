# Social_Service_Winter_2025

This repository contains code and final outputs developed during my Social Service work with **Fundación Tarahumara José A. Llaguno, A.B.P.**, focused on data validation, cleaning, and process automation. Through this project, I learned to use **pandas from the ground up**, with no prior background, and gained hands-on experience in **process automation using Selenium**, a tool I had not previously worked with.

This experience challenged my skill set at the time and reinforced an important lesson: meaningful learning and growth occur outside of one’s comfort zone. Working on tasks for which I initially lacked the necessary knowledge motivated me to learn independently, adapt quickly, and continuously seek more complex and demanding challenges.


> **Data Privacy Notice**  
> Due to privacy considerations and the presence of sensitive information, the source code and final outputs have been heavily modified to protect the identity of individuals and communities benefiting from the organization’s activities.
